# 📚 Library Management System (SQL Server)

## Overview

The **Library Management System** is a SQL Server database project designed to manage the daily operations of a library. It demonstrates database design, SQL querying, and data analysis techniques using a realistic library dataset.

This project was built to strengthen my SQL skills and showcase my ability to work with relational databases, joins, subqueries, window functions, Common Table Expressions (CTEs), and database optimization techniques.

## Features

* Manage student records
* Store book and author information
* Organize books by category
* Track book issue and return transactions
* Monitor overdue books
* Generate borrowing reports
* Analyze library activity using SQL queries

## Database Tables

* Students
* Books
* Authors
* Categories
* Book_Issue

## SQL Concepts Used

* SELECT Statements
* Filtering (WHERE)
* Sorting (ORDER BY)
* Aggregate Functions
* GROUP BY & HAVING
* INNER JOIN, LEFT JOIN
* Subqueries
* Correlated Subqueries
* EXISTS & NOT EXISTS
* Common Table Expressions (CTEs)
* Window Functions

  * ROW_NUMBER()
  * RANK()
  * DENSE_RANK()
  * LEAD()
  * LAG()
* Date Functions
* Data Manipulation (INSERT, UPDATE, DELETE)

## Sample Reports

* Most borrowed books
* Students with overdue books
* Books never borrowed
* Category-wise book count
* Monthly borrowing trends
* Daily issue reports
* Most active students
* Author-wise borrowing statistics

## Technologies Used

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)

## Purpose

This project was created as part of my SQL learning journey to practice real-world database management and solve business-oriented SQL problems. It reflects my understanding of database design and advanced SQL concepts commonly used in Data Analyst and SQL Developer roles.
